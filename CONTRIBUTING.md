# Contributing to AutoScout AI

Thank you for considering contributing to AutoScout AI!

## Code of Conduct

Please maintain a respectful, inclusive, and professional environment across all issue discussions, pull requests, and communication.

## Development Workflow

1. **Fork & Branch**: Create a feature branch from `main` using descriptive naming (`feat/connector-carscom`, `fix/ranking-algorithm`).
2. **Atomic Commits**: Write clear, concise commit messages adhering to Conventional Commits (e.g., `feat: ...`, `fix: ...`, `docs: ...`, `chore: ...`).
3. **Pull Requests**: Open a pull request against `main` with a thorough description of your changes and reference relevant issues.

## Code Standards

- **Python**: Follow PEP 8 guidelines. Keep backend packages modular and type-annotated.
- **Node.js / TypeScript**: Maintain strict typing and formatting standards across web apps and packages.
- **Clean Architecture**: Respect boundary separations between `apps/`, `packages/`, `infrastructure/`, and `docs/`.
