# AutoScout AI

An AI-powered used-car buying assistant that understands natural language queries, searches online vehicle marketplaces (starting with Cars.com), aggregates listings, ranks them intelligently, and flags potentially suspicious or scam listings.

## High-Level Goals

- **Natural Language Discovery**: Allow users to describe what car they want in plain English (e.g., *"Reliable commuter under $15k with low mileage near Chicago"*).
- **Multi-Marketplace Aggregation**: Unify vehicle listings across online platforms into a standardized schema, starting with Cars.com.
- **Intelligent Ranking Engine**: Score and rank listings based on value, market context, reliability metrics, and user preferences.
- **Automated Scam & Anomaly Detection**: Flag suspicious pricing, dubious description patterns, duplicate VINs, and red-flag seller traits.
- **Scalable Monorepo Foundation**: Maintain clean separation between API services, AI packages, data connectors, and web user interfaces.
