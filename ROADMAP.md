# AutoScout AI Roadmap

This document outlines the planned development milestones for AutoScout AI.

---

## Milestone 1: Foundation
- Project repository initialization and directory structure
- Baseline documentation, environment configuration, and developer guidelines
- CI/CD workflow scaffolding

## Milestone 2: Cars.com Connector
- Raw listing scraper / API connector for Cars.com
- Listing data normalization pipeline and unified vehicle schema definition
- Data storage and caching layer

## Milestone 3: AI Search
- Natural language query interpreter (intent parsing, constraint extraction)
- Structured query translation engine
- Semantic match scoring

## Milestone 4: Ranking Engine
- Market price analysis and fair-value estimation model
- Multi-factor listing ranking (price, mileage, location, reliability, condition)
- User preference weighting algorithm

## Milestone 5: Scam Detection
- Anomaly detection for suspicious pricing and listing text patterns
- VIN history verification & duplicate listing cross-checking
- High-risk indicator and trust badge engine

## Milestone 6: Frontend
- Web user interface (search input, listing feed, comparison matrix)
- Interactive vehicle overview and AI reasoning cards
- Saved searches and alert notifications UI

## Milestone 7: Deployment
- Infrastructure setup and containerization
- Production API deployment and Web client hosting
- Monitoring, logging, and security hardening
